## 📶 About WST

**WST WiFi Speed Test** measures internet connection performance on Android.
Compare Wi-Fi rooms, routers and mobile data using download, upload and
HTTP latency measurements, with deeper diagnostics available through Premium Lifetime.

> ### 🔔 Free App — Supported by Advertising
> WST is free and funded by **Google AdMob** advertising: adaptive banners,
> native ads, interstitials and app-open ads.  
> **Supporter One-Time** removes ads while the purchase entitlement is valid.  
> **Monthly Supporter** removes ads while the subscription is active.  
> **Premium Lifetime unlocks features — it does not remove ads.**

## ✨ Features

### 🚀 Real Connection Measurements

- ⬇️ Download speed in Mbps
- ⬆️ Upload speed in Mbps
- ⏱️ HTTP ping / response latency
- 📈 Real-time speed gauges and test results
- 📱 Wi-Fi and mobile-data connection testing

### 🌍 Automatic Server Selection

- Auto checks latency and small download/upload requests before choosing an endpoint
- Independent public LibreSpeed endpoints and Cloudflare CDN
- Alternative servers after failures or rate limits, when available
- Manual server selection for comparisons
- HTTP 429 cooldowns are respected to avoid repeated requests to a rate-limited host

### 📊 Deeper Diagnostics

- **Jitter:** variation between initial HTTP latency samples
- **Loaded-latency chart:** real HTTP response times during download and upload
- **Ping loss:** unanswered replies in a 20-probe ICMP sample to 1.1.1.1
- Unsupported, blocked or incomplete ICMP sampling is **unavailable**, not confirmed 100% loss
- Explanations of what the metrics mean

> Results are estimates, not guaranteed line capacity. Device performance,
> Wi-Fi conditions, congestion, routing and server availability affect measurements.
> Speed tests transfer data and may use a metered connection allowance.

### 🗂️ Local History

- Latest **10 results** stored on your device
- Up to **50 results** with Premium Lifetime
- **CSV export** with Premium Lifetime
- No developer-operated server stores your personal test history

## 🌐 Diagnostic Services

WST uses public diagnostic endpoints, including **Cloudflare** and
**LibreSpeed** servers operated by Clouvider, Turris, GARR and CESNET.
Legacy endpoints from Tele2, Bouygues and Online.net remain manually selectable.
ICMP loss probes use **1.1.1.1** and are separate from the HTTP speed-test server.

WST is an independent app, not affiliated with or endorsed by these providers.
Public endpoints can be unavailable or rate-limited; no uptime or measurement guarantee is made.
