## [Initial Public Release] — 2026

### Added

- Download and upload speed testing
- Ping, jitter and packet-loss estimates
- Loaded-latency samples and real-time charts
- Multiple global diagnostic endpoints
- Local test history
- Premium extended history and CSV export
- Supporter badges and eligible launcher icons
- Zero advertising SDKs

### Documentation

- Added README, Privacy Policy, Terms of Use, Support and Security documentation.
- Added standardized GitHub issue and pull-request templates.
