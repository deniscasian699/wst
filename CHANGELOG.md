## Current development — v1.14

Documentation prepared on **29 September 2026**. This section describes the
current working version; it does not assert that these changes are already
published on Google Play.

### 🔔 Advertising & Purchases

- Google AdMob adaptive banners, native, interstitial and app-open ads
- Google UMP privacy choices and consent-gated requests
- Supporter One-Time / Monthly Supporter remove ads while their entitlement is valid
- Premium Lifetime unlocks tools but still includes ads
- Request cooldowns and ad-placement loading/support fallbacks

### 🌐 Measurements

- Automatic endpoint validation and server failover
- Public LibreSpeed alternatives to the shared Cloudflare endpoint
- Host-wide HTTP 429 cooldowns and reduced request frequency
- ICMP loss sampling separate from HTTP failures, with unavailable-result handling
- Real loaded-latency samples, chart/gauge refinements and metric explanations

### 🗂️ Documentation

- Privacy, terms and presentation pages updated for advertising and diagnostics
- Public repository documentation and screenshot placeholders
