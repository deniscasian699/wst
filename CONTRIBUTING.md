# 🤝 Contributing to WST WiFi Speed Test

Thank you for your interest in WST WiFi Speed Test! 📶

</div>

---

WST WiFi Speed Test is a **proprietary application.** This repository is used for
public documentation, legal documents, issue tracking, and transparency.

Direct code contributions are not accepted at this time.

---

## 💬 How You Can Help

### 🐛 Report a Bug

Found a bug? Please open a
[GitHub Issue](../../issues/new?template=bug_report.md) with:

- Device model and Android version
- WST WiFi Speed Test version, connection type, selected server and test stage
- Steps to reproduce the bug
- Expected vs. actual behavior
- Screenshots or recordings *(if helpful)*

Or report directly at **[bugs.rdcapps.com](https://bugs.rdcapps.com)**

### 💡 Suggest a Feature

Have an idea? Open a
[Feature Request](../../issues/new?template=feature_request.md) with:

- The problem you're trying to solve
- Your proposed solution
- Why it would benefit WST WiFi Speed Test users

### 🌐 Translation

If you notice a translation error in the Romanian or English website or documentation,
please let us know at
**[support@rdcapps.com](mailto:support@rdcapps.com)**

### ⭐ Rate & Review

Leaving a positive rating and review on
[Google Play](https://play.google.com/store/apps/details?id=com.wst.wifispeedtest) helps other users
discover WST WiFi Speed Test. It's the best free way to support the app.

### ❤️ Support Development

Consider a [Supporter plan](https://play.google.com/store/apps/details?id=com.wst.wifispeedtest) to
help keep WST WiFi Speed Test free and actively maintained. Supporter One-Time
removes ads while its entitlement is valid; Monthly Supporter removes ads
while active. Premium Lifetime unlocks tools but does not remove ads.

---

## 📋 Issue Guidelines

- Search existing issues before opening a new one to avoid duplicates.
- Use clear, descriptive titles.
- Include as much context as possible, but redact personal information and order IDs.
- Be respectful and constructive.

---

## 🤝 Code of Conduct

All interactions in this repository are expected to meet basic standards
of respect and professionalism.

Harassment, spam, or abusive behavior will result in removal.
